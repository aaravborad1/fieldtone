FieldTone

Metronome · Show tempo maps · Tuner · Drone · Recorder

A free stand-in for TonalEnergy, built for marching band. The part that matters most: build a file for the whole show — every tempo, meter change, accel. and rit. in order — and let the click follow it from measure 1 to the closer.

Get going

Quick start
  1. Open the appTap Open FieldTone. Five tabs across the bottom: Metronome, Show, Tuner, Tone, Record.
  2. Tap the big play button onceThe first tap also switches on the sound (phones block audio until you touch the screen).
  3. Set tempoDrag the slider, use −1 / +1 / ±10, or tap TAP in time four times.
  4. Set the meterBeats + note value. For 6/8 counted in 2, set Beats 6 / value 8 and Count as = dotted ♩.
  5. Shape the clickTap any beat box to cycle it: normal → accent → soft → silent. Pick click sounds under Sounds.
Everything you set is saved on the device automatically — tempo, meter, sounds, shows. Close it and come back; it's how you left it.

The main event

Building a show file

Open the Show tab. A show is a list of segments, top to bottom. Each segment is a stretch of measures that share one time signature and tempo.

  1. Add a segment per tempo/meter changeHit + Segment. Give it the rehearsal letter (A, B, …) so the status line can announce "next: B".
  2. Fill in the boxesMeasures, Beats, / value, Count as, Tempo. Measure numbers (m1–16, m17–24 …) are worked out for you.
  3. For an accel. or rit., set "Ramp to"Leave it blank for a steady tempo. Put the ending BPM in and the click glides from Tempo to that value across the segment.
  4. Name and saveRename the show, then Save to library — it stays on the device. Export .json to hand the file to another director; they use Import .json.
  5. Play itPress play. You get a count-in, a running measure number, the current segment lit up, and "next: letter @ tempo". Set Start from measure to drop in anywhere.
Render click track (.wav) turns the entire show — count-in included — into one audio file. AirDrop it to any phone or laptop and play it straight through the field PA. Nothing needs FieldTone installed on the field.

Worked example

Opener A: 16 bars of 4/4 at 144. Build B: 8 bars of 4/4, Tempo 144, Ramp to 168. Ballad C: 12 bars of 3/4 at 72, Ramp to 60. Closer D: 16 bars of 4/4 at 160, Ramp to 184. Four segments, 52 measures, and the click handles every transition.

Install

Putting it on an iPhone

It runs in Safari and installs to the Home Screen like a real app — full screen, works with no signal.

  1. Open the FieldTone link in Safari(This same address. Chrome on iOS works too but Add to Home Screen is a Safari feature.)
  2. Tap the Share buttonThe square with an up-arrow, in the toolbar.
  3. Choose "Add to Home Screen"Confirm. A FieldTone icon lands on your Home Screen.
  4. Launch it from that iconNow it opens full-screen and offline. Rehearsal needs no wifi.
The tuner and recorder need the microphone, which browsers only allow over a secure (https) address. Opening this hosted link is fine. Opening the raw file off a thumb drive is not.

Output

Bluetooth speakers & the field PA

There's nothing to pair inside FieldTone. The click always plays through whatever output your phone is already using.

  • Bluetooth PA or speaker: pair it once in iOS Settings → Bluetooth. FieldTone's sound follows it automatically.
  • Wired into the sound board: run a cable from the headphone/USB-C adapter into a board channel. Same deal — the click goes where the phone's audio goes.
  • Laptop: if your browser supports it, the app shows an Output device picker under "Audio output & Bluetooth" so you can send the click to a specific interface.
To tune off the field mics, connect the mic / audio interface to the phone, open the Tuner tab, and choose it under Input source.

The rest

Tuner, drone, recorder

Tuner

Play a note. The face grins green when you're within 5 cents, goes amber then red as you drift. Set A4 and pick your Transpose (B♭ trumpet/clarinet, E♭ alto, F horn…). Needle or strobe, with a cents-history graph.

Tone / drone

A steady reference pitch to tune the ensemble against. Choose the note, octave and timbre. Runs at the same time as the metronome and tuner.

Recorder

Record a run, see the waveform, play it back, download it. Toggle "play click while recording" to keep time on the take.

Tempo trainer

On the Metronome tab: auto-bump the tempo by a set amount every few bars up to a ceiling, or randomly mute bars to test whether the section is holding time.

Fixes

Troubleshooting

No sound

Tap the play button once first — phones keep audio silent until you touch the screen. Check the ring/silent switch and the volume slider in the app.

Tuner won't start / "mic access needed"

You must be on the hosted https link, not a local file. When Safari asks for microphone permission, allow it. If you tapped no once, fix it in iOS Settings → Safari → Microphone (or Settings → the FieldTone app).

Screen keeps sleeping mid-rehearsal

"Keep screen awake while playing" is on by default. If iOS still dims it, raise Settings → Display & Brightness → Auto-Lock.

Show didn't update

Segments save as you edit. To move one, use ↑ / ↓ on that segment card. New starts a blank show — save the current one to the library first if you want to keep it.

An update didn't show up

The app caches itself to work offline. Fully close it and reopen while on wifi to pull the latest.
